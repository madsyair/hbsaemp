Citation
========

To cite hbsaemp in publications, use:

   Choir A, Kaffah MIS, Salsabiela RK (2026). *hbsaemp: Hierarchical Bayesian Small
   Area Estimation in Python*. Python package version |release|.
   https://madsyair.github.io/hbsaemp/

A BibTeX entry for LaTeX users:

.. parsed-literal::

   @Manual{,
     title = {hbsaemp: Hierarchical Bayesian Small Area Estimation in Python},
     author = {Achmad Syahrul Choir and M. Ihsan Silmi Kaffah and Rahmadika Kemala Salsabiela},
     year = {2026},
     note = {Python package version |release|},
     url = {https://madsyair.github.io/hbsaemp/},
   }

The version number follows the documentation you are reading. If you used a
different release, cite that one.
