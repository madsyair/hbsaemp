# Documentation toolchain. Pinned exactly so a CI build and a local build
# produce the same site. Resolved and verified together on 2026-09-09.
#
# Install alongside the package itself, which autodoc imports for real:
#     pip install -e ".[bambi]"
#     pip install -r docs/requirements-docs.txt
#
# `pip install -e ".[bambi]"` covers numpy, pandas, bambi, pymc, arviz,
# arviz-plots, matplotlib — everything the python/ reference and tutorials
# import at module level.
#
# gui/reference/app-internals.rst additionally autodocs hbsaemp.app, which
# imports panel, param, dcor, seaborn, and scipy at module level. Those five
# are NOT part of [bambi] (they only live in the [gui] extra alongside it),
# so they're pinned here instead of pulling the full [gui] extra — this
# keeps the docs install from also dragging in [gui]'s own transitive
# [bambi] duplicate. If hbsaemp[gui] gains a new direct import in the future,
# add it here too; the app-internals.rst build will otherwise fail with a
# ModuleNotFoundError pointing at exactly which one is missing.
